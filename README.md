## 🚀 실행 방법

### 방법 1: 배치 파일 실행 (가장 쉬움)
`실행.bat` 파일을 더블클릭하세요.

### 방법 2: 터미널에서 실행
```bash
cd health_inventory
python -m streamlit run app.py --server.port 8502
```

### 접속 주소
- **로컬**: http://localhost:8502
- **네트워크**: http://[컴퓨터IP]:8502

## ✨ 주요 기능

### 0. 학교 계정 관리
- 학교명 + 비밀번호로 계정 생성
- 어디서든 같은 정보로 로그인 → 데이터 접근

### 1. 실시간 대시보드
| 카드 | 설명 |
|------|------|
| 🔴 즉시 폐기 | 유통기한 경과 품목 |
| 🟡 교체 준비 | 90일 이내 만료 품목 |
| 🚨 재고 부족 | 현재고 < 권장 재고 |
| ✅ 정상 | 정상 보관 품목 |

- 카드 클릭 → 해당 상태 약품 목록 펼침

### 2. 의약품 목록 관리
- 분류별 / 키워드 검색 + 검색 버튼
- 상태별 탭 필터 (전체 / 즉시폐기 / 교체준비 / 재고부족 / 정상)
- 체크박스로 다중 선택 → 일괄 삭제
- 품목별 수정 / 입출고 / 삭제 버튼

### 3. 약품 등록
- **필수**: 품명, 규격/단위, 입고 수량, 유효기한
- **선택**: 분류, 권장재고, 보관위치, 관리TIP
- 유효기한 입력 시 잔여일 실시간 표시

### 4. 스마트 업로드
- 📷 사진 OCR: 약품 사진 → 유통기한 자동 인식 (easyocr)
- 📊 엑셀 일괄 업로드: xlsx/csv → 대량 등록

### 5. 입출고 이력
- 입고 / 출고 / 폐기 구분 기록
- 품명 / 구분별 필터 + 검색
- 이력 엑셀 다운로드 / 선택 삭제

### 6. 내보내기
- 📊 현재 재고 엑셀
- 🏛️ 에듀파인 등록 양식
- 📋 관리대장 출력 (서식 포함)
- 📥 일괄 업로드 양식 (빈 템플릿)
